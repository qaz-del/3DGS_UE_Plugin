# Gaussian Point Splatting renderer modes

Modes remain `gps.Render.Mode 0` (regular analytic Gaussian splats) and `gps.Render.Mode 1` (paper-inspired stochastic opaque points). Mode 2 is unsupported and warns before selecting mode 0. The depth/ID implementation in both modes now requires SM6 and 64-bit texture atomics, using R64_UINT or the R32G32_UINT alias. Unsupported views are logged and skipped.

Both modes produce per-component layers of premultiplied color and a coherent depth/source-ID pair. A shared frame pass sorts these component layers by per-pixel depth and composites front to back. Paper mode selects the nearest sampled Gaussian per subpixel, including across components. Regular mode retains its weighted color accumulation within a component; sorting component layers by representative depth remains an approximation for interleaved transparent Gaussians.

UE opaque geometry can occlude either mode through `gps.Render.UseSceneDepthTest` (default 1) with `gps.Render.SceneDepthBiasCm` (default 2 cm). SceneColor and SceneDepth ViewRects are mapped explicitly. Depth is positive view-space Z, not Clip.w or reversed device Z. Gaussian depth is an estimated Gaussian-center depth, not a reconstructed mesh surface. This is an AfterDOF composition path; it does not write UE's main SceneDepth or add collision/shadows.

The frame exposes RDG textures `GPS.Depth` (R32_FLOAT, cm, 0=no hit), `GPS.ID` (R32G32_UINT, session component ID + flat original asset index) and `GPS.Coverage` (R32_FLOAT). `gps.Debug.Output` selects normal color (0), depth (1), ID false colors (2), or coverage (3). Representative depth/ID ignores contributions below `gps.Render.DepthAlphaThreshold` (default 0.05); color is unaffected. These outputs are transient RDG textures, not Blueprint texture render targets.

`gps.Render.Supersampling 1` is the default baseline. Setting 2 renders four subpixels per output pixel in either mode. Projection, covariance floor, radius limits and sampling density scale with the grid. Depth tests and component composition happen per subpixel; the final color and coverage are averaged. The final depth/ID pair comes from the nearest qualifying subpixel and is never averaged. Texture limits cause an explicitly logged fallback to 1x1.

Paper mode runs preprocessing, budget reduction, group-local work compaction, indirect dispatch generation, opaque point splatting and layer resolve. The queue contains uint2 entries (Gaussian index, point ordinal), removing the former 25-bit Gaussian-index / 7-bit point-ordinal restriction. `gps.Paper.MaxPointsPerGaussian` is the 1x1 cap (default 128, range 1..128), scaled to 512 at 2x2. `gps.Paper.MaxWorkItems` remains an explicit total-point budget (default 16M, maximum 64M), not automatically scaled by supersampling. When RawTotal exceeds this capacity, per-Gaussian counts are stochastically reduced toward 90% of capacity. This changes coverage and must be recorded in comparisons.

Static compressed attributes remain approximately 21 bytes per selected Gaussian, plus a new 4-byte persistent source-ID mapping shared by both modes (about 200 MB total at 8M). Paper projected data is 32 bytes/Gaussian, count buffers total 8 bytes/Gaussian, and the uint2 queue uses 8 bytes/item (128 MB at the default 16M budget). Per-component layer color/hit textures, local atomic images, final outputs, RDG overhead and other UE resources are additional. At 2x2 the sample-grid textures have four times the pixel count; total VRAM does not simply scale by four.

Fixed random seeds remain the default (`gps.Paper.AnimateSeed 0`). Static views retain the same noise realization; neither static accumulation nor moving-view temporal reprojection is part of this change. Higher-order SH, self-occlusion culling and subsequent research work are outside this scope.

Screen picking is available in PIE/Standalone as `gps.Pick [U V]` (default center 0.5,0.5), and in Blueprint as the asynchronous `Pick Gaussian at Screen UV` node. UV is normalized to the constrained local-player viewport. A GPU query reads back 16 bytes only when requested, returning the source component, source asset, asset-local sample index, flat index, view depth, coverage and Gaussian center. Result delivery is asynchronous on the game thread. Requests time out after five seconds without a matching game view. Destroyed/reimported sources are rejected; stereo views are not supported. Numeric component IDs are session-local; asset/sample identity is stable while the asset revision is unchanged.

GPU timing scopes use UE 5.8's RDG_EVENT_SCOPE_STAT API; the deprecated RDG_GPU_STAT_SCOPE no longer records timings in this engine. Use stat gpu / profilegpu and CSV captures on a fixed camera sequence. See [Testing.md](Testing.md) for build commands, the manual test sequence and recording requirements. No compilation, GPU validation or performance capture has yet been performed for this change.
